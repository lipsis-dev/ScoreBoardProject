# About the Project:
Created a functional score board that can be used to track the scores of two teams, the scores can be incremented by 1, 2, or 3 points at a time with the click of a button. 
This web application was apart of Scrimba's [The Frontend Career Path](https://scrimba.com/learn/frontend) journey. 
The site is written in HTML, CSS, and JavaScript. It was developed on the [JetBrains WebStorm IDE](https://www.jetbrains.com/webstorm/)
